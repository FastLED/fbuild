# site/mirror/shards

One manifest.json `Release` per bucket owner, named by the first 16 hex digits
of the SHA-256 of the owner name, plus sixteen `names-<h>.json` shards (Index
keys `@names-<h>`) listing every package as a component `type/name/owner`,
bucketed by the first hex digit of the SHA-256 of the lowercased name.
`../manifest.json` maps owners to these files and pins each file's sha256.
Together they are fbuild's registry index (FastLED/fbuild#1829). Generated by
`ci/gen_mirror_manifest.py`; do not hand-edit.
