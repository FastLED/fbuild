fbuild Library Manager

This page needs a project and environment to know which platformio.ini to read.

Open it from a project directory with:

fbuild libraries

— that resolves the current project/env and passes them as ?project=&env= query params automatically. You can also pass them manually, e.g. ?project=/path/to/project&env=uno.
